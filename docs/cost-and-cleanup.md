# Cost and Cleanup

Local labs: no cost and no cloud resources. Delete `workspace/` when finished.

Optional API path: API calls are billed per token to the project. Prices change; check current pricing and keep a project spend limit. After the lab:
1. Revoke and delete the API key.
2. Archive the sandbox project if it was created only for the labs.
3. Confirm in the usage dashboard that consumption has stopped.

Optional workspace path: workspace agents consume credits. Delete test builds and agents, disconnect any apps you connected, reverse every setting you changed,
and confirm credit usage has stopped.
